МОСТЫ МЕЖДУ МИРАМИ — сайт-энциклопедия Дизары

СОДЕРЖИМОЕ
- index.html — сам сайт, стили и интерактивный поиск
- assets/novaya-zarya.jpg — карта Архипелага Новой Зари
- assets/new-lands.jpg — карта Новых Земель

КАК ПРОСМОТРЕТЬ ЛОКАЛЬНО
1. Распакуйте архив.
2. Откройте index.html в браузере.
3. Для работы сайта не нужны сервер, база данных или установка зависимостей.
   Интернет нужен только для загрузки декоративного шрифта Google Fonts;
   без него сайт использует системные шрифты.

КАК СДЕЛАТЬ САЙТ ПУБЛИЧНЫМ ЧЕРЕЗ GITHUB PAGES
1. Войдите в GitHub и создайте новый публичный репозиторий, например mosty-mezhdu-mirami.
2. Загрузите в корень репозитория index.html и папку assets целиком.
3. Откройте Settings → Pages.
4. В разделе Build and deployment выберите Deploy from a branch.
5. Выберите ветку main и папку / (root), затем Save.
6. После публикации GitHub покажет публичный адрес вида https://ВАШ-ЛОГИН.github.io/mosty-mezhdu-mirami/

ВАЖНО
Я подготовил файлы сайта, но не публиковал их в интернете и не создавал аккаунты/репозитории от вашего имени.
Для публикации нужен ваш GitHub-аккаунт и одноразовая загрузка этих файлов.
Сайт сейчас является открытой энциклопедией без закрытых секретов кампании.
